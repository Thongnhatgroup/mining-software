# Bắt đầu nhanh (Quick Start)

Hướng dẫn này giúp bạn triển khai phần mềm trong **15 phút**.

---

## Yêu cầu tối thiểu

- Máy tính (Windows / Mac / Linux)
- Node.js 16+ (tải từ nodejs.org)
- Tài khoản Netlify (miễn phí: netlify.com)
- Kết nối Internet

---

## 5 bước cơ bản

### Bước 1: Cài đặt (2 phút)

```bash
# Tải hoặc clone mã nguồn
cd mining-software

# Cài đặt dependencies
npm install
```

### Bước 2: Build (2 phút)

```bash
npm run build
```

Nếu thấy ✓ "built successfully" → Tiếp tục

### Bước 3: Tạo tài khoản Netlify (2 phút)

1. Truy cập https://netlify.com/
2. Đăng ký (Free)
3. Xác thực email

### Bước 4: Triển khai (5 phút)

```bash
# Đăng nhập Netlify
netlify login

# Liên kết project
netlify link

# Đặt tên: mining-[tên mỏ] (VD: mining-khuongian)

# Triển khai
netlify deploy --prod
```

### Bước 5: Kiểm thử (4 phút)

1. Mở link được cấp (VD: https://mining-khuongian.netlify.app/)
2. Đăng nhập: `baove` / `baove123`
3. Thấy giao diện Bảo vệ → Thành công! ✅
